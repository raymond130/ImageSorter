The purpsoe of this app is to offer users either a pretrained image recognition/classification model that can show them images similar to what they type into a search box (e.g. the user wants images of sunsets), and/or where the user can create a model themselves by separating some of their images into folders and attaching a tag which will be applied to images similar to those. (these custom tags could also be added to the tags a user would search on)
